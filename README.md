# Grimório dos Reinos · Duelo entre amigos

Site do modo PvP do Grimório dos Reinos: crie uma sala, mande o link do convite e jogue com um amigo, cada um no seu aparelho.

- Abra: https://f4bslacerda.github.io/grimorio-pvp/
- Também dá para treinar contra o computador (Instrutor ou Cavaleiro).

As jogadas passam pelo Firebase (Realtime Database). Os dois navegadores rodam o mesmo motor com a mesma semente; quem reconecta relê as jogadas e continua do ponto em que parou.
